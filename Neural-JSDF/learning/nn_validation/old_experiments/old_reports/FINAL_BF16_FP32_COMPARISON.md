## 🔍 방법론

### 데이터 생성

```python
# 고정된 random seed로 재현 가능한 테스트 생성
torch.manual_seed(42)
np.random.seed(42)

# 같은 입력 생성
input = generate_random_configs()

# 두 모델에 같은 입력 적용
fp32_pred = fp32_model(input)  # env/parameter
bf16_pred = bf16_model(input)   # env/parameter_bf16
mesh_truth = calculate_mesh_distance(input)
```

### 비교 메트릭

**1. 직접 예측 비교:**
- `pred_diff = |fp32_pred - bf16_pred|`
- 양자화의 직접적 영향 측정

**2. Ground Truth 대비 에러:**
- `fp32_error = |mesh_truth - fp32_pred|`
- `bf16_error = |mesh_truth - bf16_pred|`
- 실제 정확도 평가

**3. 상관 분석:**
- Pearson correlation coefficient
- 예측 일관성 평가

### 통계적 신뢰성

- **샘플 크기**: 10,000개 (충분히 큼)
- **재현성**: 고정된 random seed (seed=42)
- **공정성**: 완전히 동일한 입력 사용
- **포괄성**: 9개 링크 전체 분석
